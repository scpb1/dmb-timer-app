# Дневник

Документация модуля: личный дневник и дневник девушки солдата (письма).

## Что использовано

Проект на **Expo SDK 51** (см. `package.json`). AGENTS.md ссылается на docs Expo 57, но код пишется под установленный SDK.

| Задача | API / библиотека |
| --- | --- |
| Хранение записей и тем | `expo-sqlite` 14 (`openDatabaseAsync`, `execAsync`, `runAsync`, `getFirstAsync`, `getAllAsync`) |
| Фото | `expo-image-picker` 15 (`launchImageLibraryAsync`, `launchCameraAsync`) |
| Копирование фото в песочницу | `expo-file-system` 17 (`documentDirectory`, `copyAsync`) |
| UUID | `expo-crypto` (`randomUUID`) |
| Жесты переноса/ресайза фото | `react-native-gesture-handler` 2 + `react-native-reanimated` 3 |
| Цветовой круг | `react-native-svg` (секторы HSV) + pan/tap |
| Дата | `@react-native-community/datetimepicker` |
| Навигация | React Navigation 6, stack внутри вкладки «Дневник» |

Новые npm-зависимости не добавлялись: всё уже было в приложении.

## Архитектура

Два продукта на **одном редакторе**. Различия только в обвязке (тема дня, рандом, подтверждение смены темы).

```
Вкладка Diary
 └─ DiaryStackNavigator
     ├─ DiaryHome          две кнопки
     ├─ PersonalDiary      сразу лист на выбранную/сегодняшнюю дату
     ├─ LetterTheme        «Твоя тема на сегодня» + набор текста 32 с
     └─ LetterEditor       тот же DiaryEditor + shuffle
```

Общий лист: `src/components/diary/DiaryEditor.tsx`.

### Модель документа

Не WYSIWYG-WebView и не один большой HTML. Документ — массив блоков:

- `paragraph` — массив span’ов `{ text, style }` (размер, цвет, bold/italic/underline, шрифт)
- `image` — `uri`, `widthRatio` (доля ширины рабочей области), `aspectRatio`

Так фото вставляется «в абзац», его можно переставлять между блоками и масштабировать, не борясь с `contenteditable`.

Форматирование:

- каретка без выделения → меняется стиль печати (`typingStyle`), уже набранный текст не трогается
- есть выделение → стиль применяется к диапазону (`applyStyleToRange`)
- размер шрифта выбирается выпадающим списком в тулбаре (`14 / 16 / 18 / 22 / 28`)
- текст использует основной шрифт приложения (`dmb-timer-sans`, жирный — `dmb-timer-sans-Bold`); выбор семейства временно скрыт

Цвет: плавный круг HSV (угол = тон, радиус = насыщенность), полоса яркости с непрерывным жестом и маркером, поле HEX. Полоса — градиент от чёрного до самого светлого выбранного оттенка. Во время жеста маркеры двигаются на UI-потоке; цвет документа обновляется один раз при отпускании, чтобы не перерисовывать редактор и SVG на каждый пиксель.

### Фото

Кнопка «+» справа снизу. Вставка:

- фокус на пустом абзаце → фото становится на его место, после него остаётся пустой абзац для текста
- фокус на абзаце с текстом → фото со **следующего** абзаца (как просили)
- нет фокуса → после последнего блока

Тап по фото показывает ручки:

- слева сверху — удалить
- по центру — перенос (pan, перестановка блока по Y)
- справа снизу — размер (равномерное растяжение)

Во время изменения размера ширина и высота обновляются на UI-потоке Reanimated. React-документ получает итоговый `widthRatio` один раз после отпускания ручки, поэтому редактор не перерисовывается на каждом пикселе жеста.

Ограничения размера:

- минимум **1/6** ширины/высоты рабочей области (лист)
- максимум — не больше листа

Файлы копируются в `documentDirectory/diary/`.

### База данных

Отдельные таблицы, не JSON в `config` (темы должны жить в БД):

```sql
letter_themes (id, title, sort_order)
diary_entries (id, kind, entry_date, theme_id, content_json, updated_at)
UNIQUE(kind, entry_date)
```

Сиды тем — полный каталог в `src/data/letterThemes.ts` и список в `docs/letter-themes.md` (2000+ тем). Тон: тоска, ожидание, вера, а не устав дома. При смене `LETTER_THEMES_SEED_VERSION` каталог в БД перезаписывается. Первые три темы сохранены:

1. Наша первая встреча
2. Наше первое свидание
3. Наш первый поцелуй

`kind`: `personal` | `letter`. Одна запись на дату внутри каждого вида. Прошлые дни редактируются через календарь в шапке (будущие даты закрыты).

`resetAllData` чистит `diary_entries`, каталог тем оставляет.

Использованная тема = `theme_id` у сохранённых писем. Повторно не выдаётся. Для перевыбора темы текущего дня эта дата исключается из «занятых», чтобы можно было оставить ту же тему при рестарте анимации, но чужие занятые темы не предлагаются.

Если на дату письма попадает праздник (вкладка «События», см. `docs/events.md`), первой выдаётся виртуальная тема `Как я отмечала {название} {год}`. Каталог из 2000+ тем в этот день остаётся доступен через shuffle.

## Потоки экранов

### Личный дневник

Главная вкладки → «Личный дневник» → сразу страница **сегодня** в режиме чтения. Календарь в шапке, иконка карандаша. Редактирование: «Сохранить» и крестик (с подтверждением). «+» для фото только в режиме правки. Уход назад с несохранённым — диалог сохранить / не сохранять / отмена.

### Письма

Если на сегодня уже есть сохранённое письмо → сразу редактор.

Иначе экран темы:

- заголовок «Твоя тема на сегодня:»
- если день совпал с праздником – сначала тема «Как я отмечала {название} {год}» (см. `docs/events.md`)
- тема в «ёлочках» набирается **5 секунд**
- через **1 секунду** появляется «Я готова» (ждать набор не обязательно)
- shuffle справа сверху перезапускает экран и берёт другую свободную тему
- «Я готова» → редактор с чистого листа и выбранной темой

В редакторе писем всё как в личном, плюс shuffle в шапке:

> Точно поменять? Ваши изменения не сохранятся.

Подтверждение уводит на экран темы без записи в БД.

Если свободных тем нет — сообщение, что все темы уже использованы.

## Решения, которые сознательно приняты

1. **Блоки, а не WebView.** Нативный стек, те же жесты, что в трекерах, без новой зависимости. Курсор = фокус абзаца + selection в `TextInput`.
2. **Режим чтения по умолчанию.** Карандаш открывает правку; крестик спрашивает подтверждение и откатывает документ к последнему сохранению. Сохранение возвращает в чтение.
3. **Явное сохранение**, без автосейва. Совпадает с требованием кнопки сохранения; случайный уход не перетирает день.
4. **Перенос фото = порядок блоков**, не абсолютный холст. Иначе «вставка в абзац» и свободный drag конфликтуют. Ресайз ограничен рамкой листа.
5. **Темы в SQLite, тело записи — JSON блоков.** Темы выбираются SQL’ом, верстка листа версионируется (`document.version = 1`) и может эволюционировать без миграции столбцов.
6. **Нижняя вкладка скрывается** на теме и в редакторе, чтобы лист был рабочей областью.
