# Сообщения бота пользователям

Сводка всех текстов, которые бот отправляет в Telegram. Источники: `src/texts.ts`, `src/digest.ts`, `src/events.ts`, `src/keyboards.ts`, фрагменты в `src/bot.ts`.

**Персонализация:** многие фразы в личке проходят через `withLead` / `withTrail` / `withThanks` / `withOneSlot` (`src/address.ts`) — в начало или середину может подставляться обращение («солнышко», «милая», «родная», «дорогая», «подруга» или имя из настроек); вариант без обращения — 30%; остальные 70% поровну между ласковыми и именем из настроек.

**Разметка:** в чатах и в части личных ответов используется HTML (`parse_mode: 'HTML'`).

## Личка

### Кнопки клавиатуры

| Элемент | Текст |
|--------|--------|
| Reply-клавиатура | `🪖 Срок службы`, `📍 События`, `✍🏻 Написать автору`, `⚙️ Настройки` |
| Отмена | `Отмена` |
| Срок дембеля | `365 дней`, `547 дней` |
| Подписка (inline) | `Подписаться на канал`, `Проверить подписку` |
| События (inline) | `Добавить событие`, `Посмотреть другие события`, `Удалить праздник`, `Добавить все праздники`, `Назад` |
| Настройки (inline) | `Новые имена`, `Новые даты`, `Удалить все данные`, `Да, удалить всё`, `Назад` |
| Обратная связь (inline) | `👍🏻 Зашло`, `👎🏻 Бесит`, `🐞 Баг`, `💡 Идея` |

Команды меню бота (`/start`, `/mydmb`, `/prazdniki`, `/author`, `/cancel`) — описания в `src/index.ts`.

### /start и подписка

**Приветствие** (`greeting`):

```
Привет, {имя}! 🤍

Я твоя подружка до заветного дембеля. С моей помощью ты можешь:
– узнать сколько дней прошло с призыва и сколько дней осталось до дембеля,
– отметить армейские события,
– и ещё кое-что находится в разработке.

Моя создательница – автор канала «Девичья служба». Там она рассказывает, как разрабатывает мобильное приложение для подсчёта дней армии.

✍🏻 Если у тебя есть идеи, пожелания, критика – пиши мне, я ей обязательно передам!

❗Подпишись на канал «Девичья служба», чтобы мы могли общаться.
```

В режиме без обязательной подписки добавляется блок (жирный + подчёркнутый):  
`БОТ В РЕЖИМЕ ТЕСТИРОВАНИЯ, ПОДПИСКА НЕ ТРЕБУЕТСЯ` / `Если бот молчит, нажми на кнопку «Проверить подписку»`.

| Ситуация | Текст |
|----------|--------|
| Нет подписки | Похоже, подписки ещё нет. Подпишись на канал «Девичья служба» и нажми «Проверить подписку» ещё раз 🤍 |
| Подписка есть | Супер! Есть подписка, спасибо! (+ персонализация к «спасибо») |
| Подписка на месте (резерв) | Всё в порядке, подписка на месте 🤍 |
| Ошибка проверки | Не могу проверить подписку. Если ты уже подписана, напиши /start чуть позже. Я ещё учусь 🤍 |
| Бот не админ канала | Не могу проверить подписку. Бот должен быть админом канала «Девичья служба». |
| Всплывающий alert при проверке без подписки | Сначала подписка на канал |

### Даты службы

| Ситуация | Текст |
|----------|--------|
| Запрос призыва | Чтобы считать дни, напиши дату призыва в формате ДД.ММ.ГГГГ: |
| Запрос дембеля | Теперь напиши дату дембеля – тоже в формате ДД.ММ.ГГГГ, либо выбери количество дней ниже: |
| Неверная дата | Не получилось прочитать дату. Напиши так: ДД.ММ.ГГГГ |
| Дембель раньше призыва | Дата дембеля должна быть позже даты призыва. Напиши другую дату или выбери срок кнопкой. |
| Даты записаны (резерв, не вызывается из бота сейчас) | Отлично, я записала! |
| Нет дат для функции | Сначала укажи даты службы. Без них я не могу считать дни. |
| Смена дат в настройках | Сейчас стоят такие даты: / Призыв: … / Дембель: … / Чтобы поменять, напиши новую дату призыва… |
| Пара дат в настройках | Напиши даты призыва и дембеля в таком виде: дата призыва / дата дембеля… |
| Ошибка формата пары дат | Напиши так: ДД.ММ.ГГГГ / ДД.ММ.ГГГГ |

### Срок службы (`termMessage`)

Заголовки и вставки по фазе:

| Фаза | Заголовок и особые строки |
|------|---------------------------|
| До призыва | `💔 Служба скоро`, блок **До призыва осталось**, опционально «Завтра призыв» |
| Во время службы | `🪖 Срок службы`, даты `ДД.ММ.ГГГГ – ДД.ММ.ГГГГ`, шкала звёзд, **Прошёл/Прошло** + **Остался/Осталось**, опционально «Сегодня призыв», «Завтра дембель» |
| После дембеля | `🎖️ Служба завершена!`, **Прошло с дембеля**, опционально «Сегодня дембель» |

Под заголовками: `{N} дней` и три строки с часами, минутами, секундами (склонение по правилам русского).

В конце при наличии событий — тизер ближайшего:

- `📍 Сегодня: **{событие}** ({дата})`
- `📍 Завтра: …`
- `📍 Ближайшее событие: **{событие}** – через {N дней} ({дата})`

Если дат нет — подставляется текст «Сначала укажи даты службы…».

### События

**Список событий** — заголовок `📍 События`, строки вида:

```
{⏳|✅|🏅} **название**
d MMMM yyyy
```

| Ситуация | Текст |
|----------|--------|
| Нет дат | Сначала поставь даты службы. Тогда появятся призыв, дембель и остальные события срока. |
| Нет событий на срок | На оставшийся срок событий нет. |
| Каталог (шапка) | **Я знаю эти события:** |
| Каталог (подвал) | Напиши его название и я сама добавлю его. |
| Строка каталога | `**название** (N дней после призыва / до дембеля / половина службы)` |
| Добавить своё | Блок **Добавить событие** + инструкция и пример |
| Дата известного события | `{имя} я знаю. Напиши дату: ДД.ММ.ГГГГ или X ддд или X дпп` |
| Неизвестное название | Я не знаю такого события… |
| Добавлено | Добавила «{имя}» 🤍 |
| Уже есть | «{имя}» уже есть. |
| Вне срока службы | Событие можно поставить только после дня призыва и до дня дембеля… |
| Нет дат для события | Сначала поставь даты службы. Без них я не пойму… |
| Плохой ввод | Название не длиннее {80} символов. Дату напиши так… |
| Добавлено N штук | Добавила {N} событие/события/событий 🤍 |
| Нечего добавить массово | Новых событий нет. Они уже стоят… |
| Удаление — заголовок | **Удаление события** + нумерованный список |
| Подсказка к удалению | Напиши номер. Можно несколько через запятую. |
| Плохой номер | Не поняла номер… |
| Нечего удалять | Пока нечего удалять. |
| Удалено | Удалила событие «{имя}». (несколько — с новой строки) |

Полный перечень имён из каталога — массив `KNOWN_EVENTS` в `src/events.ts` (десятки армейских вех).

### Настройки

| Ситуация | Текст |
|----------|--------|
| Экран настроек | `⚙️ Настройки` + статусная строка + «Хочешь изменить данные?» |
| Статус до призыва | `{имя}, твой любимый {имя} уйдёт в армию {дата}.` |
| Статус после | `… окончил службу {дата}.` |
| Статус во время | `… в армии с {дата} до {дата}.` |
| Имена — запрос | Напиши оба имени через косую черту – твоё имя / имя любимого |
| Имена — ошибка формата | Напиши оба имени через /. Например, твоё имя / имя любимого |
| Имена — не хватает поля | Нужны оба имени – твоё и имя любимого |
| Имена — длина | Каждое имя не длиннее 80 символов. |
| Имена сохранены | Записала: {твоё} / {любимого}
| Удаление — подтверждение | Удалю имена, даты службы и события. Это нельзя отменить… |
| Удаление — готово | Готово, все данные удалила 🤍 |

### Обратная связь

| Шаг | Текст |
|-----|--------|
| Выбор типа | `✍🏻 Написать автору` + «Что хочешь передать автору?» |
| Текст отзыва | Теперь напиши, что хочешь сказать: |
| Слишком длинно | Слишком длинно. Уложись в 3500 символов. |
| После отправки — 👍 | Рада, что тебе понравилось! Я уже передала весточку счастья создательнице 🤍 (+ варианты с обращением) |
| После — 👎 | Создательница подумает, как можно это исправить… |
| После — 🐞 | Упс! Я очень рада, что ты сказала об этом… Твоё сообщение доставлено 🤍 (+ варианты) |
| После — 💡 | Крутая идея! Спасибо за помощь… |
| Прочее | Передала 🤍 |

*(Копия отзыва админу — отдельно, см. в конце файла.)*

### Прочее в личке

| Ситуация | Текст |
|----------|--------|
| Отмена | Ок, отменила. |
| Команда «ддд/ближайшее/календарь» про другого человека | Чужой срок и события смотри в беседе: «ддд @имя», «ближайшее @имя» или ответь на сообщение этими словами |
| Подсказка меню (резерв) | Можно смотреть срок, события или написать автору. Кнопки внизу. |
| Личное «ближайшее» | Заголовок с именем + тизер события или «На срок службы ближайших событий не осталось» |
| Личный календарь на месяц | `🪖 События пары {имена жирные подчёркнутые} на {месяц год}` + строки `д месяц – название` и `✅` у прошедших |

## Чаты (группы и супергруппы)

### Приветствие

При добавлении бота в беседу (`groupHello`):

```
Привет, девчата! Я ваша верная подружка на период армии 🤍

Я могу подсказать каждой из вас:
– срок службы (команда ддд или /mydmb);
– ближайшее событие (ближайшее или /next_event, ближайшие или /list_next_events);
– события на месяц (календарь или /list_month_events, /month_events);
– дембеля в чате (Сводка или /list_dmb);
– события на сегодня (События или /list_events)

✍🏻 Сводку ддд присылаю в настраиваемый час (по умолчанию {ЧЧ:00 МСК}). О вехах на завтра напомню вечером около {20:00 МСК}. Поздравляю с событиями в день!

Админы: Частота и Время, или /lists_settings — настройки автосводки и событий

В сводку: личка с датами, затем Новый таймер или /newdmb. Выйти: убрать меня или /out_dmb

Я рада быть здесь!
```

Команды меню в группах — `src/index.ts` (`/newdmb`, `/list_dmb`, `/list_events`, `/lists_settings`, `/next_event`, `/list_next_events`, `/month_events`, `/list_month_events`, `/out_dmb` и др.).

### Подписка и доступ в чате

| Ситуация | Текст |
|----------|--------|
| Ошибка проверки подписки | Не могу проверить подписку. Напиши мне в личку /start. |
| Нужна подписка | Чтобы я могла отвечать, подпишись на канал «Девичья служба»: {url} |
| Нет подписки (настройка в личке) | То же, что в личке: «Похоже, подписки ещё нет…» |

### Регистрация в сводке беседы

| Ситуация | Текст |
|----------|--------|
| Нет личных дат | Сначала напиши мне в личку и укажи даты |
| Встала в сводку | Супер! {имя}, теперь ты появишься в сводке и я смогу тебя поздравить с армейскими событиями 🤍 |
| Уже в сводке | Милая, ты уже зарегистрирована 🤍 |
| Вышла из сводки | {имя}, убрала тебя из сводки этого чата. Вернуться — Новый таймер или /newdmb |
| Не в сводке | Тебя нет в сводке этой беседы. Чтобы вернуться — Новый таймер или /newdmb |

Подсказки в хвостах авто- и ручной сводки:

- `Чтобы попасть в этот список, напиши мне в личку… команда Новый таймер или /newdmb`
- `Чтобы получать поздравления, напиши мне в личку…` (то же по смыслу)

### Сводка дембелей

**Заголовок:** `🪖 Ближайшие дембеля:`

**Строки участников:**

- `{имя}: {N} ддд`
- `{имя}: 💔 ПРИЗЫВ` (день призыва)
- `{имя}: 🎖️ ДЕМБЕЛЬ` (день дембеля)

При переполнении лимита Telegram — `...` и обрезка. Пустой список по запросу: заголовок + `Пусто` + подсказка про `/newdmb`.

### События сегодня и автопоздравления

**Праздники (не призыв/дембель):**

```
Поздравляю с пройденным событием! 🤍

Сегодня {человек} празднует **{название события}**.
(несколько человек — несколько строк)

{подсказка про личку и /newdmb}
```

**Пусто на сегодня:** `Сегодня ни у кого нет события` + подсказка.

**Призыв** (`groupEnlistmentCelebration`):

```
💔 ПРИЗЫВ

{имя} сегодня отправила любимого на службу

Это не повод расстраиваться, ведь таймер наконец-то начал тикать!
```

**Дембель** (`groupDemobilizationCelebration`):

```
🎖️ ДОЛГОЖДАННЫЙ ДЕМБЕЛЬ

Любимый отслужил – {имя} дождалась!

@{username} или {имя}, счастливого совместного будущего!
```

**Вечернее «завтра»:** `🌙 Завтра у {человек}: **{события через запятую}**`

### Команды в беседе (ответы)

| Команда / запрос | Ответ |
|------------------|--------|
| Срок (`ддд`, `/mydmb`, по @ или reply) | Имя жирным + полный `termMessage` (как в личке) |
| Нет своих дат | У тебя ещё нет дат службы. Напиши мне в личку, я запишу. |
| Нет дат у другого | Дат службы ещё нет. Пусть твоя подруга напишет мне в личку |
| Неизвестный пользователь | Этого человека я не знаю. Пусть напишет мне в личку /start и поставит даты. |
| Нет в чате | Этого человека нет в чате |
| Не проверить членство | Не получилось проверить, состоит ли этот человек в беседе. |
| Ближайшее (одно) | Имя + тизер или «На срок службы ближайших событий не осталось» |
| Список участников (действующие призывы) | `список участников чата` или `/list_members`. Блоки по весеннему/осеннему призыву года, внутри – весна/лето/осень/зима. Без уже дембельнувших, кроме дня дембеля – зачёркнутая строка и **ДЕМБЕЛЬ**. Пусто – `Пусто` |
| Список всех участников | `список всех участников чата` или `/list_all_members`. Те же блоки, включая прошедших. Пара после дембеля – зачёркнуто, затем 🎖️ |
| Ближайшие (все) | `📍 Ближайшие события участников чата` + строки `{человек}: **{событие}** – через …` (без слова «Ближайшее») |
| События на месяц (одни) | `🪖 События пары … на {месяц}` + события; без дат: «Сначала поставь даты службы в личке» |
| События на месяц (все) | `🪖 События участников чата на {месяц}` + блоки по парам; пусто: «В {месяц} у сводки событий нет» |
| Команда только для чата в личке | Это команда для беседы. Здесь смотри срок через /mydmb. |

Ответы на команды в группе часто идут **ответом** на исходное сообщение (quote).

### Настройки сводки (только админы)

| Ситуация | Текст |
|----------|--------|
| Не админ | Настройки списков меняет **только** администратор беседы (в alert — без HTML) |
| Экран настроек | Интервал сводки дембелей, часы сводки и событий, кнопки |
| Сохранено «никогда» | Хорошо. Автосводку в чат не присылаю. Нужна — команда Сводка или /list_dmb |
| Сохранено расписание | Хорошо. Сводка дембелей будет {интервал}, не раньше {ЧЧ:00 МСК} |
| Подсказка своего интервала | Напиши число дней. Например «Частота 10» или /lists_settings 10… от 0 до 365. |
| Час сводки | /lists_settings dmb 10 или кнопка «Час сводки дембелей» |
| Час событий | /lists_settings events 9 или кнопка «Час событий» |
| Час сохранён | Хорошо. … не раньше {ЧЧ:00 МСК} (отдельно для сводки и для событий) |

**Фразы интервала** (`digestIntervalPhrase`): каждый день / раз в неделю, каждые 7 дней / раз в месяц, каждые 30 дней / раз в {N дней} / никогда.

**Кнопки частоты (inline):** Каждый день, Раз в неделю, Раз в месяц, Никогда, Свой промежуток.

**Кнопки часа:** 09:00, 10:00, 12:00, 13:00, 18:00, 20:00.

## Как обновлять этот файл

При изменении текстов в коде сверяйте:

- `src/texts.ts` — основная копирайтинговая база;
- `src/digest.ts` — сводка, праздники, пустые состояния;
- `src/events.ts` — каталог событий и формат строк;
- `src/keyboards.ts` и `BTN` в `texts.ts` — подписи кнопок;
- `src/bot.ts` — единичные alert-тексты.
